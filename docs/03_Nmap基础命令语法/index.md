## Nmap 命令结构

### 基本语法

Nmap 的基本命令语法如下：

```bash
nmap [选项] {目标}
```

- **选项**：以 `-` 或 `--` 开头的参数，用于控制扫描行为
- **目标**：要扫描的主机或网络，可以是 IP 地址、主机名或网络范围

### 目标指定方式

Nmap 支持多种灵活的目标指定方式，以下是常用方法的汇总：

| 指定方式 | 示例 | 说明 |
|---------|------|------|
| 单个 IP | `nmap 192.168.1.1` | 扫描单个主机 |
| 主机名 | `nmap scanme.nmap.org` | 扫描指定域名的主机 |
| IP 范围 | `nmap 192.168.1.1-100` | 扫描 192.168.1.1 到 192.168.1.100 |
| CIDR 表示法 | `nmap 192.168.1.0/24` | 扫描整个子网（256 个主机） |
| 多目标 | `nmap 192.168.1.1 192.168.1.100 scanme.nmap.org` | 同时扫描多个目标 |
| 排除目标 | `nmap 192.168.1.0/24 --exclude 192.168.1.1` | 扫描子网但排除指定主机 |
| 从文件读取 | `nmap -iL target.txt` | 从文件读取目标列表 |

!!! example "示例：多种目标指定方式"
    ```bash
    # 扫描单个主机
    nmap 192.168.1.1
    
    # 扫描整个 C 类子网
    nmap 192.168.1.0/24
    
    # 扫描 IP 范围
    nmap 192.168.1.1-50
    
    # 排除特定主机
    nmap 192.168.1.0/24 --exclude 192.168.1.1,192.168.1.100
    
    # 从文件读取目标
    echo -e "192.168.1.1\n192.168.1.100\nscanme.nmap.org" > targets.txt
    nmap -iL targets.txt
    ```

### 选项分类概览

Nmap 的选项可以分为以下几大类：

| 分类 | 前缀 | 说明 | 示例 |
|------|------|------|------|
| **扫描类型** | `-s` | 指定扫描方式 | `-sS`（SYN 扫描）、`-sT`（TCP 连接扫描） |
| **端口指定** | `-p` | 指定要扫描的端口 | `-p 80`、`-p 1-100`、`-p-` |
| **输出控制** | `-o` | 控制输出格式和保存位置 | `-oN`（普通输出）、`-oX`（XML 输出） |
| **时序模板** | `-T` | 控制扫描速度和隐蔽性 | `-T0`（偏执模式）、`-T4`（激进模式） |
| **详细程度** | `-v`/`-d` | 控制输出详细程度 | `-v`（详细）、`-vv`（更详细）、`-d`（调试） |
| **主机发现** | `-P` | 控制主机发现方式 | `-Pn`（跳过主机发现）、`-PE`（ICMP Echo） |
| **Evasion** | `-f`/`--data-length` 等 | 绕过防火墙和 IDS | `-f`（分片）、`-D`（诱饵） |

## 扫描类型参数

扫描类型是 Nmap 最核心的参数，决定了 Nmap 如何探测目标主机的端口状态。不同的扫描类型适用于不同的场景，理解其原理对于正确使用 Nmap 至关重要。

### 常用扫描类型详解

#### 1. TCP SYN 扫描（`-sS`）

**原理**：SYN 扫描是 Nmap 的默认扫描方式。它发送一个 SYN 包到目标端口，根据响应判断端口状态：
- 收到 SYN-ACK：端口开放（open）
- 收到 RST：端口关闭（closed）
- 无响应或被过滤：端口被过滤（filtered）

**特点**：
- 不需要完成 TCP 三次握手，因此称为"半开扫描"（half-open scanning）
- 速度快，不易被目标系统记录
- 需要 root 权限（发送原始包）

**示例**：
```bash
# 使用 SYN 扫描扫描目标主机
sudo nmap -sS 192.168.1.1

# 扫描特定端口
sudo nmap -sS -p 80,443 192.168.1.1
```

#### 2. TCP 连接扫描（`-sT`）

**原理**：通过调用操作系统的 `connect()` 系统调用完成完整的 TCP 三次握手。

**特点**：
- 不需要 root 权限
- 速度较慢（完成完整连接）
- 容易被目标系统记录和触发警报
- 当 SYN 扫描不可用时的备选方案

**示例**：
```bash
# 使用 TCP 连接扫描
nmap -sT 192.168.1.1

# 扫描常用端口
nmap -sT -p 22,80,443 192.168.1.1
```

#### 3. UDP 扫描（`-sU`）

**原理**：发送 UDP 包到目标端口，根据响应判断端口状态：
- 收到 UDP 响应：端口开放（open）
- 收到 ICMP 端口不可达错误：端口关闭（closed）
- 无响应：端口被过滤（filtered）

**特点**：
- UDP 扫描速度较慢（需要等待超时）
- 常用于发现 DNS、SNMP、DHCP 等服务
- 可以结合 `-sS` 同时进行 TCP 和 UDP 扫描

**示例**：
```bash
# UDP 扫描
sudo nmap -sU 192.168.1.1

# 同时扫描 TCP 和 UDP
sudo nmap -sS -sU -p 53,80,443 192.168.1.1
```

#### 4. Ping 扫描（`-sP` / `-sn`）

**原理**：仅进行主机发现，不扫描端口。发送 ICMP Echo 请求、TCP SYN 到 443 端口、TCP ACK 到 80 端口等探测包。

**特点**：
- 快速发现网络中存活的主机
- 不进行端口扫描，隐蔽性较好
- 新版 Nmap 推荐使用 `-sn` 替代 `-sP`

**示例**：
```bash
# 发现子网中存活的主机
nmap -sn 192.168.1.0/24

# Ping 扫描单个主机
nmap -sn 192.168.1.1
```

#### 5. FIN/NULL/Xmas 扫描（`-sF` / `-sN` / `-sX`）

**原理**：发送非常规 TCP 包（FIN、NULL、Xmas），根据 RFC 793 规定，关闭的端口应该返回 RST 包。

**特点**：
- 可以绕过某些非状态化防火墙和包过滤器
- 仅适用于 UNIX 系统（Windows 不遵循 RFC 793）
- 结果可能不可靠

**示例**：
```bash
# FIN 扫描
sudo nmap -sF 192.168.1.1

# NULL 扫描（无标志位）
sudo nmap -sN 192.168.1.1

# Xmas 扫描（FIN+URG+PUSH）
sudo nmap -sX 192.168.1.1
```

#### 6. ACK 扫描（`-sA`）

**原理**：发送 ACK 包，用于探测防火墙规则（状态化或非状态化）。

**特点**：
- 不能确定端口是否开放，只能判断是否被过滤
- 常用于映射防火墙规则集

**示例**：
```bash
# ACK 扫描（探测防火墙）
sudo nmap -sA 192.168.1.1
```

#### 7. 窗口扫描（`-sW`）

**原理**：类似 ACK 扫描，但检查返回 RST 包的窗口大小，某些系统会为开放端口返回正值窗口。

**示例**：
```bash
sudo nmap -sW 192.168.1.1
```

#### 8. Maimon 扫描（`-sM`）

**原理**：发送 FIN-ACK 包，某些 BSD 系统会在开放端口丢弃此包。

**示例**：
```bash
sudo nmap -sM 192.168.1.1
```

### 扫描类型对比表格

| 扫描类型 | 参数 | 原理 | 优点 | 缺点 | 适用场景 |
|---------|------|------|------|------|---------|
| **SYN 扫描** | `-sS` | 发送 SYN，不完成握手 | 快速、隐蔽、结果准确 | 需要 root 权限 | 大多数 TCP 扫描场景（推荐） |
| **TCP 连接扫描** | `-sT` | 完成完整 TCP 连接 | 不需要特权、可靠 | 慢、易被记录 | 无 root 权限时 |
| **UDP 扫描** | `-sU` | 发送 UDP 数据包 | 发现 UDP 服务 | 慢、结果可能不准确 | 发现 DNS、SNMP 等服务 |
| **Ping 扫描** | `-sn` | 仅主机发现 | 快速、隐蔽 | 不扫描端口 | 网络存活主机发现 |
| **FIN 扫描** | `-sF` | 发送 FIN 包 | 可绕过某些防火墙 | 结果不可靠、Windows 无效 | 绕过简单防火墙 |
| **NULL 扫描** | `-sN` | 无标志位 | 隐蔽 | 结果不可靠 | 同上 |
| **Xmas 扫描** | `-sX` | FIN+URG+PUSH | 隐蔽 | 结果不可靠 | 同上 |
| **ACK 扫描** | `-sA` | 发送 ACK 包 | 探测防火墙规则 | 不能确定端口开放状态 | 防火墙规则探测 |
| **窗口扫描** | `-sW` | 检查 RST 窗口大小 | 可判断端口状态 | 仅适用于某些系统 | 特定系统探测 |
| **Maimon 扫描** | `-sM` | FIN-ACK 包 | 绕过某些 BSD 防火墙 | 适用范围窄 | BSD 系统探测 |

!!! warning "权限要求"
    大多数扫描类型（如 `-sS`、`-sU`、`-sF` 等）需要 root/administrator 权限，因为它们需要发送原始网络包。在 Linux 系统中，需要使用 `sudo` 执行 Nmap。

## 端口指定参数

端口指定是 Nmap 扫描中的重要环节。合理指定端口可以显著提高扫描效率，避免浪费时间扫描无关端口。

### `-p` 参数的各种用法

`-p` 参数用于指定要扫描的端口，支持多种灵活的指定方式。

#### 1. 单端口扫描

```bash
# 扫描单个端口
nmap -p 80 192.168.1.1

# 扫描 HTTPS 端口
nmap -p 443 192.168.1.1
```

#### 2. 端口范围扫描

```bash
# 扫描端口范围（1 到 100）
nmap -p 1-100 192.168.1.1

# 扫描常用端口范围
nmap -p 1-1024 192.168.1.1
```

#### 3. 连续端口列表

```bash
# 扫描多个连续端口（用逗号分隔）
nmap -p 22,80,443 192.168.1.1

# 结合范围和列表
nmap -p 1-100,443,8080 192.168.1.1
```

#### 4. 不连续端口

```bash
# 扫描不连续的端口
nmap -p 21,25,53,80,110,143,443,993,995 192.168.1.1
```

#### 5. 全端口扫描

```bash
# 扫描所有 65535 个端口
nmap -p- 192.168.1.1

# 等价于
nmap -p 1-65535 192.168.1.1
```

!!! tip "全端口扫描的时间"
    全端口扫描（`-p-`）会扫描所有 65535 个端口，耗时较长。建议结合时序模板（如 `-T4`）使用，或在初步扫描后针对特定端口进行详细扫描。

#### 6. 指定协议（TCP/UDP）

```bash
# 扫描 TCP 端口
nmap -p T:80,443 192.168.1.1

# 扫描 UDP 端口
nmap -p U:53,161 192.168.1.1

# 同时指定 TCP 和 UDP
nmap -p T:80,443,U:53,161 192.168.1.1
```

#### 7. 基于服务名称的端口指定

```bash
# 扫描 HTTP 服务对应的端口（80, 443, 8080 等）
nmap -p http 192.168.1.1

# 扫描 SSH 服务
nmap -p ssh 192.168.1.1
```

### `--exclude-ports` 排除端口

使用 `--exclude-ports` 可以排除某些端口，不进行扫描。

```bash
# 扫描所有端口但排除 80 和 443
nmap -p- --exclude-ports 80,443 192.168.1.1

# 排除端口范围
nmap -p- --exclude-ports 1-1000 192.168.1.1
```

### `-F` 快速模式

快速模式（`-F`）仅扫描 `nmap-services` 文件中列出的常用 100 个端口，适合快速探测。

```bash
# 快速扫描（仅扫描常用 100 端口）
nmap -F 192.168.1.1

# 等价于
nmap --top-ports 100 192.168.1.1
```

### `--top-ports` 扫描最常用端口

```bash
# 扫描最常用的 1000 个端口
nmap --top-ports 1000 192.168.1.1

# 扫描最常用的 10 个端口
nmap --top-ports 10 192.168.1.1
```

## 输出控制参数

Nmap 提供丰富的输出控制选项，可以将扫描结果保存为多种格式，方便后续分析和报告编写。

### 详细程度参数

#### `-v` / `-vv` / `-vvv` 详细模式

`-v`（verbose）参数增加输出的详细程度，可以叠加使用。

```bash
# 详细输出（显示扫描进度）
nmap -v 192.168.1.1

# 更详细的输出
nmap -vv 192.168.1.1

# 非常详细的输出
nmap -vvv 192.168.1.1
```

**详细程度说明**：
- 无 `-v`：仅显示重要结果
- `-v`：显示扫描进度和基本信息
- `-vv`：显示更多调试信息
- `-vvv`：显示所有可用信息

#### `-q` 静默模式

`-q`（quiet）参数减少输出，仅显示关键信息。

```bash
# 静默模式
nmap -q 192.168.1.1
```

### 输出格式参数

Nmap 支持多种输出格式，可以满足不同场景的需求。

#### 1. 普通输出（`-oN`）

将结果保存为普通文本格式，适合人类阅读。

```bash
# 保存为普通文本
nmap -oN result.txt 192.168.1.1

# 同时输出到屏幕和文件
nmap -oN - 192.168.1.1  # "-" 表示标准输出
```

#### 2. XML 输出（`-oX`）

将结果保存为 XML 格式，适合程序解析和自动化处理。

```bash
# 保存为 XML 格式
nmap -oX result.xml 192.168.1.1

# 同时生成普通和 XML 输出
nmap -oA result 192.168.1.1  # 生成 result.nmap, result.xml, result.gnmap
```

#### 3. Grepable 输出（`-oG`）

将结果保存为 Grepable 格式，适合用 grep、awk 等工具处理。

```bash
# 保存为 Grepable 格式
nmap -oG result.gnmap 192.168.1.1

# 结合 grep 提取开放端口
nmap -oG - 192.168.1.1 | grep "open"
```

## Nmap 命令结构

### 基本语法

Nmap 的基本命令语法如下：

```bash
nmap [选项] {目标}
```

- **选项**：以 `-` 或 `--` 开头的参数，用于控制扫描行为
- **目标**：要扫描的主机或网络，可以是 IP 地址、主机名或网络范围

### 目标指定方式

Nmap 支持多种灵活的目标指定方式，以下是常用方法的汇总：

| 指定方式 | 示例 | 说明 |
|---------|------|------|
| 单个 IP | `nmap 192.168.1.1` | 扫描单个主机 |
| 主机名 | `nmap scanme.nmap.org` | 扫描指定域名的主机 |
| IP 范围 | `nmap 192.168.1.1-100` | 扫描 192.168.1.1 到 192.168.1.100 |
| CIDR 表示法 | `nmap 192.168.1.0/24` | 扫描整个子网（256 个主机） |
| 多目标 | `nmap 192.168.1.1 192.168.1.100 scanme.nmap.org` | 同时扫描多个目标 |
| 排除目标 | `nmap 192.168.1.0/24 --exclude 192.168.1.1` | 扫描子网但排除指定主机 |
| 从文件读取 | `nmap -iL target.txt` | 从文件读取目标列表 |

!!! example "示例：多种目标指定方式"
    ```bash
    # 扫描单个主机
    nmap 192.168.1.1
    
    # 扫描整个 C 类子网
    nmap 192.168.1.0/24
    
    # 扫描 IP 范围
    nmap 192.168.1.1-50
    
    # 排除特定主机
    nmap 192.168.1.0/24 --exclude 192.168.1.1,192.168.1.100
    
    # 从文件读取目标
    echo -e "192.168.1.1\n192.168.1.100\nscanme.nmap.org" > targets.txt
    nmap -iL targets.txt
    ```

### 选项分类概览

Nmap 的选项可以分为以下几大类：

| 分类 | 前缀 | 说明 | 示例 |
|------|------|------|------|
| **扫描类型** | `-s` | 指定扫描方式 | `-sS`（SYN 扫描）、`-sT`（TCP 连接扫描） |
| **端口指定** | `-p` | 指定要扫描的端口 | `-p 80`、`-p 1-100`、`-p-` |
| **输出控制** | `-o` | 控制输出格式和保存位置 | `-oN`（普通输出）、`-oX`（XML 输出） |
| **时序模板** | `-T` | 控制扫描速度和隐蔽性 | `-T0`（偏执模式）、`-T4`（激进模式） |
| **详细程度** | `-v`/`-d` | 控制输出详细程度 | `-v`（详细）、`-vv`（更详细）、`-d`（调试） |
| **主机发现** | `-P` | 控制主机发现方式 | `-Pn`（跳过主机发现）、`-PE`（ICMP Echo） |
| **Evasion** | `-f`/`--data-length` 等 | 绕过防火墙和 IDS | `-f`（分片）、`-D`（诱饵） |

## 扫描类型参数

扫描类型是 Nmap 最核心的参数，决定了 Nmap 如何探测目标主机的端口状态。不同的扫描类型适用于不同的场景，理解其原理对于正确使用 Nmap 至关重要。

### 常用扫描类型详解

#### 1. TCP SYN 扫描（`-sS`）

**原理**：SYN 扫描是 Nmap 的默认扫描方式。它发送一个 SYN 包到目标端口，根据响应判断端口状态：
- 收到 SYN-ACK：端口开放（open）
- 收到 RST：端口关闭（closed）
- 无响应或被过滤：端口被过滤（filtered）

**特点**：
- 不需要完成 TCP 三次握手，因此称为"半开扫描"（half-open scanning）
- 速度快，不易被目标系统记录
- 需要 root 权限（发送原始包）

**示例**：
```bash
# 使用 SYN 扫描扫描目标主机
sudo nmap -sS 192.168.1.1

# 扫描特定端口
sudo nmap -sS -p 80,443 192.168.1.1
```

#### 2. TCP 连接扫描（`-sT`）

**原理**：通过调用操作系统的 `connect()` 系统调用完成完整的 TCP 三次握手。

**特点**：
- 不需要 root 权限
- 速度较慢（完成完整连接）
- 容易被目标系统记录和触发警报
- 当 SYN 扫描不可用时的备选方案

**示例**：
```bash
# 使用 TCP 连接扫描
nmap -sT 192.168.1.1

# 扫描常用端口
nmap -sT -p 22,80,443 192.168.1.1
```

#### 3. UDP 扫描（`-sU`）

**原理**：发送 UDP 包到目标端口，根据响应判断端口状态：
- 收到 UDP 响应：端口开放（open）
- 收到 ICMP 端口不可达错误：端口关闭（closed）
- 无响应：端口被过滤（filtered）

**特点**：
- UDP 扫描速度较慢（需要等待超时）
- 常用于发现 DNS、SNMP、DHCP 等服务
- 可以结合 `-sS` 同时进行 TCP 和 UDP 扫描

**示例**：
```bash
# UDP 扫描
sudo nmap -sU 192.168.1.1

# 同时扫描 TCP 和 UDP
sudo nmap -sS -sU -p 53,80,443 192.168.1.1
```

#### 4. Ping 扫描（`-sP` / `-sn`）

**原理**：仅进行主机发现，不扫描端口。发送 ICMP Echo 请求、TCP SYN 到 443 端口、TCP ACK 到 80 端口等探测包。

**特点**：
- 快速发现网络中存活的主机
- 不进行端口扫描，隐蔽性较好
- 新版 Nmap 推荐使用 `-sn` 替代 `-sP`

**示例**：
```bash
# 发现子网中存活的主机
nmap -sn 192.168.1.0/24

# Ping 扫描单个主机
nmap -sn 192.168.1.1
```

#### 5. FIN/NULL/Xmas 扫描（`-sF` / `-sN` / `-sX`）

**原理**：发送非常规 TCP 包（FIN、NULL、Xmas），根据 RFC 793 规定，关闭的端口应该返回 RST 包。

**特点**：
- 可以绕过某些非状态化防火墙和包过滤器
- 仅适用于 UNIX 系统（Windows 不遵循 RFC 793）
- 结果可能不可靠

**示例**：
```bash
# FIN 扫描
sudo nmap -sF 192.168.1.1

# NULL 扫描（无标志位）
sudo nmap -sN 192.168.1.1

# Xmas 扫描（FIN+URG+PUSH）
sudo nmap -sX 192.168.1.1
```

#### 6. ACK 扫描（`-sA`）

**原理**：发送 ACK 包，用于探测防火墙规则（状态化或非状态化）。

**特点**：
- 不能确定端口是否开放，只能判断是否被过滤
- 常用于映射防火墙规则集

**示例**：
```bash
# ACK 扫描（探测防火墙）
sudo nmap -sA 192.168.1.1
```

#### 7. 窗口扫描（`-sW`）

**原理**：类似 ACK 扫描，但检查返回 RST 包的窗口大小，某些系统会为开放端口返回正值窗口。

**示例**：
```bash
sudo nmap -sW 192.168.1.1
```

#### 8. Maimon 扫描（`-sM`）

**原理**：发送 FIN-ACK 包，某些 BSD 系统会在开放端口丢弃此包。

**示例**：
```bash
sudo nmap -sM 192.168.1.1
```

### 扫描类型对比表格

| 扫描类型 | 参数 | 原理 | 优点 | 缺点 | 适用场景 |
|---------|------|------|------|------|---------|
| **SYN 扫描** | `-sS` | 发送 SYN，不完成握手 | 快速、隐蔽、结果准确 | 需要 root 权限 | 大多数 TCP 扫描场景（推荐） |
| **TCP 连接扫描** | `-sT` | 完成完整 TCP 连接 | 不需要特权、可靠 | 慢、易被记录 | 无 root 权限时 |
| **UDP 扫描** | `-sU` | 发送 UDP 数据包 | 发现 UDP 服务 | 慢、结果可能不准确 | 发现 DNS、SNMP 等服务 |
| **Ping 扫描** | `-sn` | 仅主机发现 | 快速、隐蔽 | 不扫描端口 | 网络存活主机发现 |
| **FIN 扫描** | `-sF` | 发送 FIN 包 | 可绕过某些防火墙 | 结果不可靠、Windows 无效 | 绕过简单防火墙 |
| **NULL 扫描** | `-sN` | 无标志位 | 隐蔽 | 结果不可靠 | 同上 |
| **Xmas 扫描** | `-sX` | FIN+URG+PUSH | 隐蔽 | 结果不可靠 | 同上 |
| **ACK 扫描** | `-sA` | 发送 ACK 包 | 探测防火墙规则 | 不能确定端口开放状态 | 防火墙规则探测 |
| **窗口扫描** | `-sW` | 检查 RST 窗口大小 | 可判断端口状态 | 仅适用于某些系统 | 特定系统探测 |
| **Maimon 扫描** | `-sM` | FIN-ACK 包 | 绕过某些 BSD 防火墙 | 适用范围窄 | BSD 系统探测 |

!!! warning "权限要求"
    大多数扫描类型（如 `-sS`、`-sU`、`-sF` 等）需要 root/administrator 权限，因为它们需要发送原始网络包。在 Linux 系统中，需要使用 `sudo` 执行 Nmap。

## 端口指定参数

端口指定是 Nmap 扫描中的重要环节。合理指定端口可以显著提高扫描效率，避免浪费时间扫描无关端口。

### `-p` 参数的各种用法

`-p` 参数用于指定要扫描的端口，支持多种灵活的指定方式。

#### 1. 单端口扫描

```bash
# 扫描单个端口
nmap -p 80 192.168.1.1

# 扫描 HTTPS 端口
nmap -p 443 192.168.1.1
```

#### 2. 端口范围扫描

```bash
# 扫描端口范围（1 到 100）
nmap -p 1-100 192.168.1.1

# 扫描常用端口范围
nmap -p 1-1024 192.168.1.1
```

#### 3. 连续端口列表

```bash
# 扫描多个连续端口（用逗号分隔）
nmap -p 22,80,443 192.168.1.1

# 结合范围和列表
nmap -p 1-100,443,8080 192.168.1.1
```

#### 4. 不连续端口

```bash
# 扫描不连续的端口
nmap -p 21,25,53,80,110,143,443,993,995 192.168.1.1
```

#### 5. 全端口扫描

```bash
# 扫描所有 65535 个端口
nmap -p- 192.168.1.1

# 等价于
nmap -p 1-65535 192.168.1.1
```

!!! tip "全端口扫描的时间"
    全端口扫描（`-p-`）会扫描所有 65535 个端口，耗时较长。建议结合时序模板（如 `-T4`）使用，或在初步扫描后针对特定端口进行详细扫描。

#### 6. 指定协议（TCP/UDP）

```bash
# 扫描 TCP 端口
nmap -p T:80,443 192.168.1.1

# 扫描 UDP 端口
nmap -p U:53,161 192.168.1.1

# 同时指定 TCP 和 UDP
nmap -p T:80,443,U:53,161 192.168.1.1
```

#### 7. 基于服务名称的端口指定

```bash
# 扫描 HTTP 服务对应的端口（80, 443, 8080 等）
nmap -p http 192.168.1.1

# 扫描 SSH 服务
nmap -p ssh 192.168.1.1
```

### `--exclude-ports` 排除端口

使用 `--exclude-ports` 可以排除某些端口，不进行扫描。

```bash
# 扫描所有端口但排除 80 和 443
nmap -p- --exclude-ports 80,443 192.168.1.1

# 排除端口范围
nmap -p- --exclude-ports 1-1000 192.168.1.1
```

### `-F` 快速模式

快速模式（`-F`）仅扫描 `nmap-services` 文件中列出的常用 100 个端口，适合快速探测。

```bash
# 快速扫描（仅扫描常用 100 端口）
nmap -F 192.168.1.1

# 等价于
nmap --top-ports 100 192.168.1.1
```

### `--top-ports` 扫描最常用端口

```bash
# 扫描最常用的 1000 个端口
nmap --top-ports 1000 192.168.1.1

# 扫描最常用的 10 个端口
nmap --top-ports 10 192.168.1.1
```

## 输出控制参数

Nmap 提供丰富的输出控制选项，可以将扫描结果保存为多种格式，方便后续分析和报告编写。

### 详细程度参数

#### `-v` / `-vv` / `-vvv` 详细模式

`-v`（verbose）参数增加输出的详细程度，可以叠加使用。

```bash
# 详细输出（显示扫描进度）
nmap -v 192.168.1.1

# 更详细的输出
nmap -vv 192.168.1.1

# 非常详细的输出
nmap -vvv 192.168.1.1
```

**详细程度说明**：
- 无 `-v`：仅显示重要结果
- `-v`：显示扫描进度和基本信息
- `-vv`：显示更多调试信息
- `-vvv`：显示所有可用信息

#### `-q` 静默模式

`-q`（quiet）参数减少输出，仅显示关键信息。

```bash
# 静默模式
nmap -q 192.168.1.1
```

### 输出格式参数

Nmap 支持多种输出格式，可以满足不同场景的需求。

#### 1. 普通输出（`-oN`）

将结果保存为普通文本格式，适合人类阅读。

```bash
# 保存为普通文本
nmap -oN result.txt 192.168.1.1

# 同时输出到屏幕和文件
nmap -oN - 192.168.1.1  # "-" 表示标准输出
```

#### 2. XML 输出（`-oX`）

将结果保存为 XML 格式，适合程序解析和自动化处理。

```bash
# 保存为 XML 格式
nmap -oX result.xml 192.168.1.1

# 同时生成普通和 XML 输出
nmap -oA result 192.168.1.1  # 生成 result.nmap, result.xml, result.gnmap
```

#### 3. Grepable 输出（`-oG`）

将结果保存为 Grepable 格式，适合用 grep、awk 等工具处理。

```bash
# 保存为 Grepable 格式
nmap -oG result.gnmap 192.168.1.1

# 结合 grep 提取开放端口
nmap -oG - 192.168.1.1 | grep "open"
```

#### 4. 全部格式输出（`-oA`）

同时生成所有格式的

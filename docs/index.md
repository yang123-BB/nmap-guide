# Nmap 入门指南

欢迎来到 **Nmap 入门指南** 实验课程！

本套课程由 **LabEx** 提供，旨在帮助初学者从零开始学习 Nmap 网络扫描工具的使用。

## 课程简介

Nmap（Network Mapper）是世界上最流行的网络扫描工具，被系统管理员、网络工程师和安全研究人员广泛使用。通过本套课程，你将学习到：

- Nmap 的安装与基本配置
- 基础命令语法和参数使用
- 各种端口扫描技术（TCP Connect、SYN Stealth、UDP 等）
- 目标和端口指定技术
- 输出格式和保存方法
- 操作系统和服务版本检测
- 实战扫描策略和安全评估方法

## 课程大纲

本套课程共包含 **15 个实验章节**，内容涵盖从入门到进阶的各个方面：

| 章节 | 标题 | 内容概要 |
|------|------|----------|
| 01 | Nmap安装和基本用法 | 安装配置 Nmap，学习基本命令 |
| 02 | 本地验证服务版本 | 验证本地运行服务的版本信息 |
| 03 | Nmap基础命令语法 | 掌握 Nmap 命令结构和常用参数 |
| 04 | 寻找开放端口 | 使用 Nmap 发现目标主机的开放端口 |
| 05 | 扫描和输出分析 | 理解扫描结果并分析输出 |
| 06 | 输出保存为XML | 将扫描结果保存为 XML 格式 |
| 07 | 目标指定技术 | 灵活指定扫描目标（IP、CIDR、主机名等） |
| 08 | 从文件扫描目标 | 从文件批量读取目标进行扫描 |
| 09 | 详细程度级别 | 调整 Nmap 输出的详细程度 |
| 10 | 揭开神秘端口的面纱 | 深入理解端口扫描原理 |

## 学习建议

1. **按顺序学习**：建议从第 01 章开始，循序渐进地完成所有实验
2. **动手实践**：每个章节都包含实战练习，务必亲自操作
3. **理解原理**：不要只记住命令，要理解背后的网络原理
4. **遵守法律**：仅在授权环境下使用 Nmap 进行扫描
